This page runs entirely in your browser using the Google Maps JavaScript API. Paste a key below to load the map and route lookup, then type a full address or place name into each field. The key stays in this tab only and is never sent anywhere except Google.

How to get a key (2 minutes)
  1. Open the Google Cloud Console and create a project, then enable billing (Google gives a recurring free credit).
  2. Under APIs & Services → Library, enable Maps JavaScript API, Geocoding API, and Directions API.
  3. Under Credentials, create an API key.
  4. Restrict the key to those three APIs, and add an HTTP referrer restriction for the domain where you host this file. Set a daily quota so costs stay capped.
