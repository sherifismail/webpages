Connect a Google Maps key to begin

This page runs entirely in your browser using current Google Maps services: Maps JavaScript API for the map, Places API (New) for search suggestions, Geocoding for your location, and the Routes API for distance and travel time. Start typing a place in either field to see suggestions, or paste coordinates as lat, lng. The key stays in this tab only and is sent only to Google.

How to get a key (2 minutes)
  1. Open the Google Cloud Console, create a project, and enable billing (Google gives a recurring free credit).
  2. Under APIs & Services → Library, enable Maps JavaScript API, Geocoding API, Places API (New), and Routes API. Leave the legacy Directions and Places APIs off.
  3. Under Credentials, create an API key.
  4. Restrict the key to those four APIs, and add an HTTP referrer for the site that serves this file (e.g. https://you.github.io/*). Set a daily quota to cap costs.
