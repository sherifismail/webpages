Connect a Google Maps key to begin

This page runs entirely in your browser. It uses the Maps JavaScript API for the map, your Geocoder for locations, and the Routes API for distance and travel time — all current, non-legacy services. Type a full address or place name into each field. The key stays in this tab only and is sent only to Google.

How to get a key (2 minutes)
  1. Open the Google Cloud Console, create a project, and enable billing (Google gives a recurring free credit).
  2. Under APIs & Services → Library, enable Maps JavaScript API, Geocoding API, and Routes API. Leave the legacy Directions and Places APIs off — this page doesn't use them.
  3. Under Credentials, create an API key.
  4. Restrict the key to those three APIs, and add an HTTP referrer for the site that serves this file (e.g. https://you.github.io/*). Set a daily quota to cap costs.
